fin_dash

View-only household dashboard. No buy / sell actions. Prices may be delayed.

Masking hides every dollar amount as **** (percentages, quantities and symbols stay visible). It is a display mask only — tap the eye again to show values.

Holdings

Symbol Last price Today's gain/loss Total gain/loss Current value % of account Quantity Cost basis Day range 52-week range

Click a holding row for its price + volume chart. Last price is refreshed from the market-data API on the first dashboard load of the day (intraday price while the market is open, the close once it has closed; free tiers are delayed, not real-time) — it is not the price frozen in your import file. Day range and 52-week range come from the same API pull (Yahoo regularMarketDayLow/High and fiftyTwoWeekLow/High); without a quote they show as a dash, not an estimate.

Formulas: Total gain/loss = Current value − Cost basis (total, i.e. cost per share × quantity). Today's gain/loss = (Last price − Previous close) × Quantity. Gains are green, losses are red.

Growth vs VOO

Growth is based on current holdings held over the whole period, not actual purchase dates. Both series are indexed to 100 at the start of the selected range.

Allocation

Share of total current value, by symbol (across accounts).

What to watch

Rule-based observations only — not investment advice, and not a buy or sell recommendation.

    Add / import

    Import any brokerage export — Fidelity, Schwab, E*TRADE, or a generic CSV — and the dashboard converts it to Fidelity format automatically (Schwab's Cost Basis is treated as a total, E*TRADE's Total Cost / Price Paid as total / per-share, title lines and cash/total rows skipped). No separate conversion step is needed. Re-importing the same account + symbol updates it instead of duplicating it. See sample_holdings.csv or the Fidelity-format sample in the repo (sample_fidelity.csv) for the format.

    Export CSV downloads the holdings the dashboard currently shows. Download backup downloads the whole fin_dash database (holdings, accounts, quotes, history cache) — it does not include Plaid access tokens, which live in the separate local plaid_tokens.json file.

    Plaid sync (self-hosted only)

    Checking Plaid status…

    This is not Muse's Plaid connection — that connection's credentials do not transfer to your Mac. This needs your own Plaid developer account: set PLAID_CLIENT_ID and PLAID_SECRET in a local .env (gitignored), start with PLAID_ENV=sandbox, and restart the server. Plaid Link itself authenticates the brokerage; no dashboard login is added. Sync creates accounts named “Institution — Account (Plaid)” and re-syncing updates the same account + symbol instead of duplicating it — so do not also CSV-import the same brokerage under a different account name, or the holding will appear twice. Plaid cost basis is treated as a total cost (divided by quantity for storage). See README for the full setup steps.
